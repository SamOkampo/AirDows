Antes de empezar

Preguntas frecuentes.

¿Funciona entre redes diferentes?

Sí. AirDows intenta una conexión directa y puede usar una ruta de respaldo si alguna red la bloquea. La velocidad depende de ambos dispositivos y sus conexiones.

¿Tengo que instalar una aplicación?

No para comenzar. Funciona en el navegador y también puedes instalarla como aplicación web si tu dispositivo ofrece esa opción.

¿AirDows guarda mis archivos?

No crea un enlace para descargarlos después. Los dos dispositivos deben estar conectados durante el envío.

¿Funciona en iPhone?

Sí desde Safari. Mantén la pantalla activa durante transferencias grandes para evitar que el sistema pause la pestaña.
