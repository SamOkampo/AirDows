Common questions

Does AirDows change resolution or bitrate?

No. It transfers the selected file without re-encoding it.

Is there a fixed file-size limit?

AirDows currently imposes no fixed application limit. Practical capacity depends on the browser, device storage, memory mode, and network stability.

Are videos stored in the cloud?

No download link is created. Both devices remain active while the file travels.
