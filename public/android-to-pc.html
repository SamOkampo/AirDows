Quick answer

Open AirDows in Chrome and on your PC. Generate a code on the PC, enter it on Android, select your files, and wait for confirmation before closing either page.

Android to PC, step by step

  1. Open AirDows on the PCChoose receive and generate a temporary PIN or QR code.
  2. Connect from Chrome on AndroidOpen AirDows, choose send, and use the code displayed by the PC.
  3. Select one or more filesChoose images, videos, documents, or downloads from Android.
  4. Watch the queueAirDows sends files sequentially for stability. You can cancel the active file or remove a waiting item.

Share menu

On compatible Android systems, the installed PWA can appear as a share destination.

Keep Chrome active

Battery saving can limit browser work in the background during a transfer.

Prefer local Wi-Fi

The same Wi-Fi often provides a faster direct route, although AirDows also works across different networks.

Common questions

Do I need to install AirDows?

No. You can start in the browser; PWA installation is optional.

Can I send multiple files?

Yes. AirDows places them in a sequential queue to preserve stability.

Does it work on mobile data?

Yes, but speed and data use depend on coverage and the available network route.
