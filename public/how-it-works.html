How it works

How your file travels

AirDows connects two devices that are online at the same time. It does not create a download link or store the file for later.

Three steps from start to finish

Pair the devices

One device creates a QR code and a four-digit temporary PIN. The other scans or enters it. An unused room expires after three minutes.

AirDows finds a route

It first attempts a direct WebRTC connection between the browsers. If network conditions block that path, an encrypted TURN relay forwards the session traffic.

The receiver saves the file

Supported browsers can write directly to disk. Other browsers temporarily assemble the file in memory before offering the download.

What each route means

Direct route

The two browsers communicate with each other. This is usually the fastest path when both networks allow it.

Relay route

A TURN provider forwards encrypted traffic while the session is active. It does not create a persistent copy or a later download link.

What you should know

  • Speed depends on both devices, their networks, and the selected route.
  • Both devices must stay connected until the transfer finishes.
  • Locking a phone or closing the tab can pause or interrupt a transfer.
  • Browser-based Bluetooth transfer is not currently offered because support is inconsistent, especially on iOS.
  • The signaling server does not receive the contents of your files.
In short: AirDows moves a file now between two active devices. It is not cloud storage.
