Privacidad

Privacidad sin letra pequeña

Tus archivos se transfieren durante una sesión entre dos dispositivos. AirDows no los guarda para ofrecer una descarga posterior.

Última actualización: 18 de julio de 2026

Qué ocurre con tus archivos

Si la ruta es directa

El contenido viaja entre los dos navegadores conectados.

Si se usa la ruta de respaldo

Un proveedor reenvía los datos mientras la sesión está activa. AirDows no escribe una copia permanente del archivo en su servidor.

El servidor de emparejamiento no recibe el contenido de tus archivos. Su función es ayudar a que los dos dispositivos se encuentren y comiencen la conexión.

Datos que usamos para operar el servicio

  • Un código de emparejamiento e identificadores temporales mientras la sesión está activa.
  • Datos técnicos necesarios para seguridad, límites de uso y prevención de abuso, como la dirección de red que realiza una solicitud.
  • Contadores generales de transferencias completadas, fallidas o canceladas.
  • Categorías de ruta, velocidad, duración y tamaño. Se usan rangos, no el tamaño exacto del archivo.
  • Uso general de páginas y botones mediante Umami para entender dónde abandonan los usuarios.

Lo que no enviamos a las métricas

  • El nombre o contenido del archivo.
  • El texto compartido mediante el portapapeles.
  • El código de emparejamiento.
  • El tamaño exacto del archivo.
  • Mensajes completos de error que puedan contener información del dispositivo.

Servicios que ayudan a operar AirDows

  • Railway: aloja la aplicación y el servidor de emparejamiento.
  • Metered: ofrece la ruta de respaldo cuando dos redes no pueden conectarse directamente.
  • Supabase: guarda métricas generales del funcionamiento del servicio.
  • Umami: mide visitas y pasos del embudo de uso.
  • Telegram: envía alertas internas sobre fallos o límites operativos. Estas alertas no incluyen nombres ni contenido de archivos.

Datos en tu dispositivo

La aplicación web puede guardar temporalmente información para reanudar una transferencia o preparar archivos recibidos desde el menú Compartir. Puedes eliminarla borrando los datos del sitio desde la configuración del navegador.

Las salas sin usar expiran después de tres minutos. Las métricas generales se conservan para comparar la salud del servicio a lo largo del tiempo.
